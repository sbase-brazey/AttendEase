# AttendEase

AttendEase is an Expo attendance app for teachers and students. Attendance records, the class schedule, and test-clock settings are stored locally on the device using AsyncStorage. They are not synced between devices, and existing Firebase records are not imported.

## Local login

- Teacher: `teacher@gmail.com` / `teacher123`
- Student: use a listed student ID as both the username and password.

## Run the app

Install dependencies with `npm install`, then start Expo with `npm start`.
